Pengantar HTML

HyperText Markup Language (HTML) adalah bahasa markup standar yang digunakan untuk membuat halaman web. HTML menyediakan struktur dasar konten halaman web dan bekerja bersama CSS dan JavaScript.

Elemen Semantik HTML

Elemen semantik HTML adalah elemen yang memiliki makna atau arti yang spesifik untuk membantu mesin pencari dan pengembang memahami struktur halaman web serta meningkatkan aksesibilitas.
